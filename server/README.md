# Servidor

Esta pasta receberá a API e o mecanismo de sincronização do Proviziona.

## Base planejada

- PHP 8.3 ou superior;
- [Elavora API Framework](https://github.com/Elavora/api-framework);
- [Elavora API Skeleton](https://github.com/Elavora/api-skeleton);
- banco SQL;
- API comum à Proviziona Cloud e às instalações self-hosted.

O scaffold do Elavora será incorporado em uma mudança própria. Assim, o histórico mostrará com clareza quais arquivos vieram da base do framework e quais decisões pertencem ao domínio do Proviziona.
