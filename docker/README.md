# Self-host

Esta pasta receberá a infraestrutura oficial para executar o servidor do Proviziona.

O objetivo é chegar a uma instalação semelhante a:

```bash
docker compose up -d
```

Antes disso, o projeto precisa estabilizar a API, o banco e as rotinas de migração, backup e atualização. Ainda não há uma configuração funcional de self-host neste repositório.
